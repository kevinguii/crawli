Use this guide to source the gifs, sounds, and stock footage you need for ideas #1–3. All links are free or freemium; none require logins (except where noted).

## Reaction gifs (for split-screen chaos montage or optional inserts)

**Use case:** If you want to add quick reaction gifs to punctuate the chaos or approval moments (Idea #1 chaos montage, for example), or if you want to avoid showing your face in one version and use generic reaction gifs instead.

### Giphy (free, no login needed)
- Go to: https://giphy.com/
- Search terms for "chaos/overwhelmed":
  - "stressed typing"
  - "frustrated computer"
  - "face palm"
  - "overwhelmed"
  - "headdesk"
- Search terms for "satisfied/approved":
  - "thumbs up"
  - "nodding"
  - "satisfied smile"
  - "yes"
  - "perfect"
- **Copy the `.gif` URL** (not the share URL) — right-click the gif, "Copy image link"
- Paste into a browser tab, download the `.gif` file, import into Resolve

### Tenor (free, no login needed)
- Go to: https://tenor.com/
- Same search terms as Giphy
- Click the gif, then "Copy GIF Link" (top-right), use that link in Resolve

**Pro tip:** For Shorts, shorter gifs (1–2 sec) work best. Longer reaction gifs can be sped up in Resolve (right-click > Speed > 1.5x or 2x).

## Sound effects & music (royalty-free)

### YouTube Audio Library (free, requires Google login, but zero copyright strikes)
- Go to: https://www.youtube.com/audiolibrary (you must be logged into YouTube)
- Click "Sounds" (tab on the left)
- Search for:
  - **Chaotic/tense:** "digital chaos," "busy," "alert," "notification," "scanning"
  - **Reveal/success:** "success," "positive," "ding," "chime," "celebration," "bright"
  - **Calm/satisfying:** "ambient," "calm," "peaceful," "resolved," "relief"
- Each sound shows duration and usage rights (all are free for YouTube Shorts use)
- Download as `.mp3` or `.wav`
- Drag into Resolve timeline

### Freesound.org (free account, no download limit)
- Go to: https://freesound.org/
- Create a free account
- Search for:
  - **"card flip"** (for reveal transitions) — https://freesound.org/search/?q=card+flip
  - **"notification"** (for reveals/success) — https://freesound.org/search/?q=notification
  - **"whoosh"** (for transitions) — https://freesound.org/search/?q=whoosh
  - **"ding" or "bell"** (for approvals) — https://freesound.org/search/?q=bell+notification
- Filter by "Length: 0–5 seconds" for short sound effects
- Most sounds are Creative Commons (free to use in videos)
- Download and drag into Resolve

### Epidemic Sound (freemium)
- Go to: https://www.epidemicsound.com/
- Free account allows browsing and listening; paid ($9.99/mo) allows downloads
- If you want to try before buying: search for the sound names above, listen to samples (good for finding the exact vibe)
- This is a backup if YouTube Audio Library or Freesound don't have what you want

**Pro tip for Shorts:** Trending sounds matter. Check what sounds other "before/after" or "comparison" Shorts are using (watch some on YouTube Shorts, note the sound, then search for it on YouTube Audio Library or Epidemic Sound).

## Screen recording tools (for Crawli demos)

### Built-in to Mac:
- **QuickTime Player** (free, built into macOS)
  - Open QuickTime Player
  - File > New Screen Recording
  - Click "Record"
  - Click the screen you want to record
  - Stop when done
  - Export as `.mov` (which Resolve can import directly)

### Built-in to Windows:
- **Xbox Game Bar** (free, built into Windows)
  - Press `Win + G`
  - Click "Capture"
  - Click "Start recording"
  - Stop with `Win + Alt + R`
  - Saves as `.mp4`

### Alternative (multi-platform):
- **OBS Studio** (free, open-source)
  - Download: https://obsproject.com/
  - Set up a scene with just your screen
  - Hit "Start Recording"
  - Export as `.mp4`

**For this project:** QuickTime (Mac) or Xbox Game Bar (Windows) is plenty. No need for OBS unless you want advanced options (framerates, bitrate, etc.).

## Resolve-compatible file formats

**Video:**
- `.mp4` (most common)
- `.mov` (Mac)
- `.avi` (Windows)
- `.mkv` (universal)
- Avoid `.webm` or `.m4v` (Resolve sometimes struggles)

**Audio:**
- `.mp3` (most common)
- `.wav` (lossless, better for editing)
- `.aac` (good for YouTube)

**Images/stills:**
- `.png` (transparency preserved)
- `.jpg` (fine for screenshots)
- `.tiff` (high-quality, large files)

**Gifs:**
- `.gif` (Resolve handles these fine)

**Tip:** If a file won't import into Resolve, right-click it, "Get Info," and check the file extension. Rename if needed (e.g., `.gifv` → `.gif`).

## Quick checklist for each video

**Before you shoot:**

- [ ] Have you identified the real Poshmark/Grailed listing you'll use? (Screenshot it)
- [ ] Have you searched that item in Crawli and screenshotted the sold comps? (Real data only)
- [ ] Do you have QuickTime (Mac) or Xbox Game Bar (Windows) open and ready to screen-record?
- [ ] Have you chosen one sound for "chaos," one for "reveal"? (Downloaded to your Downloads folder)
- [ ] Have you found a good lighting spot for on-camera footage? (Natural window light is best)
- [ ] Have you charged your phone/camera battery?

**Before you edit in Resolve:**

- [ ] All .mp4, .mov, .wav, .gif files are in one folder (or organize into subfolders: "video," "audio," "gifs")
- [ ] You have 2–3 takes of each on-camera moment (so you can pick the best one)
- [ ] You've watched each screen recording once to confirm it's good
- [ ] You've listened to each audio file to confirm it's the right one

**During Resolve assembly:**

- [ ] Did you test the text in both light and dark mode?
- [ ] Are all text overlays positioned outside the bottom 20% and right 15%?
- [ ] Did you hard-cut (no transition) between clips? (Resolve: right-click clip > Dissolve, set to 0 frames)
- [ ] Does the sound drop hit exactly when the reveal happens? (Drag audio clips to sync with video)
- [ ] Did you export at 1080×1350 (4:5 aspect ratio)?

**Before you upload to Shorts:**

- [ ] Does it look good on a phone screen? (Test by AirDropping to your phone and opening it)
- [ ] Is it 3–5 seconds? (Shorts algorithm favors snappy hooks)
- [ ] Does it make sense without sound? (Shorts users often watch muted first)
- [ ] Does the text read in both light and dark themes? (Test on your phone in both)

## Resolve tips & shortcuts

**Time-stretch audio to match video:**
- Right-click audio clip in timeline
- Select "Retime" > "Speed" > manually adjust or use the slider
- Drag the end of the clip to shorten/lengthen it

**Sync sound to a beat:**
- Play the video on mute
- Play the sound separately
- Find the exact frame where you want the sound to "hit"
- Drag the audio clip's start point to that frame

**Hard cut between clips:**
- Select both clips
- Right-click > Dissolve > set duration to 0 frames (or just delete any default transition)

**Add drop shadow to text:**
- Text clip in timeline > right-click > open in Fusion
- In Fusion, add a "Shadow" node
- Adjust blur/offset/opacity to taste

**Export for Shorts:**
- File > Export > Export Video
- Format: MP4
- Resolution: 1080×1350
- Framerate: 30fps
- Codec: H.264
- Quality: "High" or "Medium" (Medium is fine for Shorts)

# Crawli Journey Series

Pubity-style narrative carousels: one real, documented person's story told in short chronological beats (hook → 5-6 beats → lesson → soft tie-in), instead of the fact-carousel format's listicle structure. See `docs/superpowers/specs/2026-07-07-journey-carousel-format-design.md` for the full design rationale.

## Format

9 slides: hook (unresolved tension, no name yet) → 5 beats (one real photo + one short line each, 5-12 words) → lesson (the arc resolves into one takeaway) → tie-in (soft Crawli aside, decoupled from the subject's story, plus a source citation) → cta (explicit Crawli call-to-action, closing the post).

## CTA policy

Unlike the fact-carousel batches (`../POSTS_README.md`), which follow an obfuscate-commercial-intent rule (no URL, no "search Crawli," Crawli mentioned only as a subtle aside on select posts), the journey series closes every post with a dedicated, explicit CTA slide: Crawli badge, direct call-to-action line, and the URL. This is a deliberate exception, not an oversight. Reasoning: a journey post already reads as editorial commentary on a real, cited story (not a disguised ad), so the tie-in slide carries the soft narrative close while the final slide can afford to ask directly, the same way a magazine feature can end with a subscribe link after the article is done. Keep the CTA slide visually consistent with the series look (same font pairing, same full-bleed-photo + scrim template) — only the badge/caption/CTA-line content changes.

## Photo policy

Real photography only, no AI generation, no unlicensed third-party press photos. Priority order:
1. Free commercial-use licensed stock (Unsplash License / Pexels License) of the literal object/scene.
2. The subject's own public social content (screenshot/frame), where directly commenting on that specific post — not yet used in this pilot; a future post could add this if the footage is actually sourced.
3. AI-generated b-roll — last resort only, never a fabricated face of the real person.

Every post's `images/CREDITS.md` records the source URL and license for each photo.

## Protagonist policy

Real names and real, publicly reported story facts are used under editorial commentary — we are retelling and citing an already-published story, not fabricating one or using someone's likeness to imply endorsement. The final slide always carries a source citation (outlet names). The Crawli tie-in never implies the subject uses or endorses Crawli.

## Visual system — signature look (fixed across the series)

Font pairing: Fraunces (headings/captions) + Work Sans (small UI text). Layout: full-bleed real photo + bottom scrim + chapter counter (beats + lesson slide) + one caption line. This look is intentionally **fixed** across every journey post — unlike the fact-carousel batches, which rotate font/layout/placement every batch, this series stays visually consistent so it reads as a recognizable format. Only the accent color varies per story.

## Caption format

Same TikTok title/description rules as the fact-carousel series (`../POSTS_README.md` "Caption Format" section), plus a source-citation line in the description naming the real person and outlets. Unlike the fact-carousel series, the description may end with a direct Crawli CTA line (see "CTA policy" above) since the explicit-ask exception applies to captions too.
